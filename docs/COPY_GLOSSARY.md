# HåfaPass copy glossary

Use plain, accurate, short copy. Describe the saved outcome; distinguish a request from a completed action. Never invent CHamoru text.

| Term | Use |
| --- | --- |
| HåfaPass | Product name in visible text. Keep HafaPass as a search alias, identifier or technical name where needed. |
| Organizer | Person or organization running an event and selling its tickets. |
| Organization team | People with access across an organization. |
| Event team | People assigned to one event. |
| Ticket | Admission for one attendee. Creating a complimentary ticket does not check it in. |
| Order | Purchase containing one or more tickets and any extras. |
| Service fee | HåfaPass fee on an order. Do not call it a tax. |
| Organizer proceeds | Money owed to the organizer after applicable fees and refunds. |
| Payout | Transfer or recorded payment of organizer proceeds. A request is not proof of payment. |
| Sign in / Sign out | Account access actions. |
| Save / Saved | Keep an event for later. Use “saved events,” not “favorites.” |
| Guam time | Label for Pacific/Guam times. Events elsewhere retain their own time zone. Platform finance operations use Guam time. |
| Village or city | Venue location, for example Tamuning. Do not default this to Guam. |
| Launch reviews | Admin launch checks. Gate letters may identify the corresponding runbook. |

Use sentence case for new buttons and labels. Preserve proper names and acronyms. Show money in dollars in forms, even when an API stores integer cents. Label timestamps with their time zone.
